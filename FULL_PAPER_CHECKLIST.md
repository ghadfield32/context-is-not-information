# Full-paper completion checklist

This checklist defines the finish line for a strong DPV manuscript. It is
intentionally narrower than the complete World Model Sports player/team/trade
platform.

## A. Preserve submission provenance

- [x] Preserve the October 1 submitted repository state.
- [x] Create `submitted-abstract-2026-10-01`.
- [x] Keep full-paper development separate.
- [x] Record the submission snapshot commit in `SUBMISSION_SNAPSHOT.md`.

## B. Consolidate the current paper

- [x] Working manuscript created.
- [x] Primary results summarized in one place.
- [x] Scientific evidence states documented.
- [x] Claim ledger retained.
- [x] Data/rights/reproduction limitations explicit.
- [x] Research roadmap separated from current claims.
- [ ] Expand related work into a citation-complete literature matrix.
- [ ] Convert the manuscript into the venue-required final format if invited.
- [ ] Final copy edit and notation audit.

## C. Close historical reproduction

- [ ] Recover the exact historical player-game fact input.
- [ ] Recover the exact historical team-game fact input.
- [ ] Re-run the frozen transition experiment.
- [ ] Retain episode-level targets and model predictions.
- [ ] Reconstruct the daily task from a pinned historical box-score vintage.
- [ ] Produce a rights-reviewed minimal public evaluation package.
- [ ] Add an executable reproduction entry point.
- [ ] Verify all headline numbers from a clean clone.
- [ ] Replace the current blocker receipt with a successful reproduction receipt.

If the historical inputs cannot be recovered:

- [ ] Define a new explicit data vintage.
- [ ] Re-run as a **new experiment**, not as historical reproduction.
- [ ] Keep historical and new-vintage results distinct in the manuscript.

## D. Historical H0 → H1 → H2 extension

- [ ] Freeze exact accepted runner bytes.
- [ ] Run H0 parity and stop on mismatch.
- [ ] Run H1 workload-trajectory model.
- [ ] Run H2 production-trajectory model.
- [ ] Repeat in a second isolated output directory.
- [ ] Retain models, scalers and predictions.
- [ ] Report MSE, RMSE, MAE, bias, P90 and P95.
- [ ] Report player-cluster uncertainty.
- [ ] Report issuance-date sensitivity.
- [ ] Produce cohort/error tables with independent support counts.
- [ ] Decide whether H1/H2 belong in the main manuscript or supplement.

## E. Core figures/tables

Target a small set of high-information visuals.

- [ ] **Figure 1:** Context-value map — daily gain vs transition degradation.
- [ ] **Figure 2:** Transition model ladder — recent / prior / history / context / fallback / shrinkage.
- [ ] **Figure 3:** Failure localization — fold-level excess error and support.
- [ ] **Table 1:** Unified primary results and uncertainty.
- [ ] **Table 2:** Cohort/error diagnostics.
- [ ] Optional: H0/H1/H2 trajectory figure if the new experiment adds a useful result.

## F. Prospective evidence

The registered prospective C0/C1/C2 study remains separate.

- [ ] Qualify Q0 event/outcome sources.
- [ ] Qualify Q1 career sources.
- [ ] Qualify Q2 opportunity sources.
- [ ] Qualify Q3 health sources.
- [ ] Require authentic `available_at <= issuance`.
- [ ] Begin immutable prospective issuance only after qualification.
- [ ] Preserve every abstention/missed issuance.
- [ ] Keep the registered design unchanged by historical H1/H2 results.

Prospective evidence is valuable if mature in time, but it is not required to
finish the core retrospective manuscript.

## G. Next major extension after the paper

- [ ] Build participation risk set.
- [ ] Estimate calibrated P(play).
- [ ] Estimate conditional minutes.
- [ ] Estimate conditional production.
- [ ] Build coherent joint rotation.
- [ ] Feed accepted player/rotation states into future-team forecasting.

Do **not** make the current paper wait for:

- optimal trade timing;
- full contract/pick valuation;
- tax/market economics;
- three-team optimization;
- production frontend completion.

## H. Final release gate

Before a final manuscript/research release:

- [ ] All public claims mapped to evidence.
- [ ] All primary tables regenerated from retained evidence.
- [ ] No internal/agent/session provenance in reviewer-facing files.
- [ ] No private filesystem paths.
- [ ] No secrets or credentials.
- [ ] Rights review complete for every public data artifact.
- [ ] Clean-clone reproduction passes.
- [ ] Independent scientific review completed.
- [ ] Final Git manifest generated.
- [ ] Immutable research-release tag created.
