# Scientific status

This file is the compact claim boundary for the DPV research program.

## Evidence states

| State | Meaning |
|---|---|
| **PRIMARY** | In the submitted abstract and supported by retained study reports |
| **SECONDARY** | Executed analysis that may support interpretation but is not a primary abstract claim |
| **POST_HOC** | Executed after examining earlier results; useful diagnostically, not confirmatory |
| **PLANNED** | Designed but not yet executed on the target evidence |
| **BLOCKED** | Cannot currently be executed or promoted because a prerequisite is missing |

## Current evidence

| Study component | Status | What it establishes |
|---|---|---|
| Daily context | **PRIMARY** | Simple daily context yields a small average retrospective gain |
| Consecutive-day cohort | **PRIMARY** | The daily-context gain reverses in this cohort |
| Transition history ridge | **PRIMARY** | Player history is a strong conditional-minutes baseline |
| Rich destination context | **PRIMARY** | Naive/rich context can materially worsen transition forecasts |
| Player-cluster uncertainty | **PRIMARY** | Adverse transition contrast under player clustering |
| Issuance-date clustering | **PRIMARY sensitivity** | Dependence assumptions materially affect uncertainty |
| Fold-1 concentration | **PRIMARY diagnostic** | Transition damage is heavily concentrated in the earliest fold |
| Support-aware fallback | **POST_HOC** | Detecting unsupported context reduces damage but does not beat history |
| Shrinkage | **POST_HOC** | Removes nearly all measured damage; incremental benefit over history remains unestablished |
| Advanced-metric augmentation | **SECONDARY** | Small additional retrospective signal on narrower coverage |
| Annual/career model | **SECONDARY** | Structured player history has longer-horizon retrospective signal |
| H0 → H1 → H2 trajectory study | **PLANNED / development** | Not an empirical result until native execution and review complete |
| Prospective C0/C1/C2 | **BLOCKED** | Source availability/qualification not yet sufficient |
| Participation P(play) | **PLANNED** | Not yet established |
| Joint rotation | **PLANNED** | Not yet established |
| Trade alternatives / profitability | **PLANNED** | Not established by forecast accuracy |
| Financial benefit | **PLANNED** | Not established |

## Claims currently allowed

The evidence supports:

1. More context is not automatically more predictive information.
2. Simple daily context can add a small average signal while failing in a
   specific short-rest cohort.
3. Player-history signals can remain useful across roster transitions.
4. A richer destination-context specification can materially degrade
   conditional-minutes forecasts.
5. Support restrictions and shrinkage can reduce that damage, but current
   diagnostics do not establish robust incremental benefit over history.
6. Forecast value is not equivalent to personnel-decision or financial value.

## Claims currently prohibited

Do not claim:

- causal rest effects;
- injury effects;
- calibrated participation probability;
- optimal rotations;
- optimal trade timing;
- causal trade value;
- player-income improvement;
- team-profit improvement;
- superiority of the full WMS player-value system;
- prospective confirmation of the historical findings.
